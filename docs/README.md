# WIRE_TO_GATE MVP protocol candidate

This repository contains an approval-neutral **content snapshot**, not an approved ProtocolRelease. Machine-readable JSON Schema, the content manifest, external approval attestation, errors, examples, vectors, runner/result contracts and the integration-slice index are authoritative. Markdown is explanatory only.

Run `pnpm install --frozen-lockfile`, `pnpm manifest:finalize` and `pnpm g1`. A PASS proves content and attestation consistency and reports their independent hashes. It does not turn a `PENDING` attestation into human G0 approval or prove either product implementation, G2/G3, real RIoT, real IO, target hardware or factory qualification.
