# WIRE_TO_GATE MVP protocol candidate

This repository contains a **candidate**, not an approved ProtocolRelease. Machine-readable JSON Schema, manifests, errors, examples, vectors, runner/result contracts and the integration-slice index are authoritative. Markdown is explanatory only.

Run `pnpm install --frozen-lockfile` and `pnpm g1`. A PASS proves only candidate-internal consistency. It does not prove human G0 approval, either product implementation, G2/G3, real RIoT, real IO, target hardware or factory qualification.
